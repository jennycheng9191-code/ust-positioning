# 美債部位與波動追蹤（ust-positioning）

每週自動更新的靜態網站：把 CFTC 的美債部位報告變成一張可讀的圖——
六檔美債合約、五類交易人，誰在加倉、部位多極端、殖利率波動如何變化。

## 這個站在回答什麼

| 模組 | 問題 |
|:--|:--|
| M1 部位結構 | 現在誰站在哪一邊？各類交易人的多空規模與淨部位。 |
| M2 本週誰在加倉 | 這一週部位往哪裡動？是新增單邊部位，還是反向部位平倉。 |
| M3 部位極端度 | 現在的部位相對 2006 年以來的歷史有多極端？ |
| M4 已實現波動 | 2Y／10Y／30Y 殖利率的實際波動在放大還是收斂？ |

對美債而言最有訊號的一組是 **Asset Manager 淨多 vs Leveraged Funds 淨空**，
這組對峙是基差交易（basis trade）規模的體溫計。

## 資料來源

| 資料 | 來源 | 頻率 |
|:--|:--|:--|
| 部位 | CFTC Commitments of Traders，TFF 期貨＋選擇權合併版（Socrata `yw9f-hn96`） | 週二收盤，當週五 15:30 ET 公布 |
| 殖利率 | FRED `DGS2` / `DGS5` / `DGS10` / `DGS30`（原始為美國財政部 CMT） | 每日 |

用「期貨＋選擇權合併版」而不是「僅期貨版」是刻意的：合併版把選擇權部位以
delta 加權後併入，所以本站的「部位」已包含選擇權的方向性曝險。

兩者皆為美國聯邦政府公開資料，依 17 U.S.C. §105 不受著作權保護，可自由使用與再散布。

> **本專案原本要做的是 CME 履約價層級的選擇權未平倉分析。**
> 技術上完全可行，但 CME Data Terms of Use 明文禁止以腳本系統性擷取其資料建立資料庫、
> 禁止再散布、也禁止 AI 相關用途，加密碼閘或設 private repo 都無法解決——
> 被禁的是「抓取建庫」這個動作本身。完整稽核見 AI 分身資料夾的
> `100_Todo/projects/2026-08-22_美債選擇權_資料源稽核.md`。

## 目錄

```
scripts/
  common.py    路徑、HTTP、UTF-8 輸出
  cftc.py      COT 抓取（含 Socrata 分頁）與欄位對應表
  fred.py      殖利率抓取
  derive.py    淨部位、週變化、極端度、已實現波動
  build.py     主流程，產出 data/
  validate.py  產出檢查（過期門檻、恆等式、列數）
  reconcile.py 對 CFTC 原始報告的外部對帳
  test_transform.py  回歸測試（不連網）
data/
  latest.json       網頁吃的那份
  cot_history.csv   完整週歷史，2006 起，28,100 列
docs/verification.md  對帳紀錄
```

## 本機執行

```bash
pip install -r requirements.txt
python scripts/test_transform.py   # 回歸測試
python scripts/build.py            # 抓取並產出
python scripts/validate.py         # 檢查
python -m http.server 8765         # 開 http://127.0.0.1:8765/
```

## 密碼

```bash
python scripts/set_password.py     # 在本機設定，只把 PBKDF2 雜湊寫進 assets/gate.js
```

這是**前端軟鎖**，不是存取控制。repo 是 public，`data/latest.json` 與
`data/cot_history.csv` 都能直接用網址開啟繞過閘門，原始碼在 GitHub 上也看得到。
它擋的是「隨手點進網址的人」與搜尋引擎收錄，不是有心人。

附帶一提，本站的資料本來就是美國聯邦政府的公開報告，任何人都能自己去 CFTC 下載——
所以這道門擋的是這個網頁介面，不是資料本身的機密性。要真正鎖住得改用
伺服器端驗證（Cloudflare Access 等）並把 repo 轉 private（Pages 免費方案不支援）。

`build.py` 是冪等的：資料沒變時產出的檔案位元組完全相同，所以排程不會累積空 commit。

## 排程

`.github/workflows/update.yml` 一週跑三次：

| 時間（台北） | 用意 |
|:--|:--|
| 週六 09:17 | 主場。CFTC 週五 15:30 ET 發布後幾小時。 |
| 週六 21:17 | 對 GitHub 排程延遲避險。 |
| 週二 09:17 | 遇美國假日 CFTC 順延至週一發布時，由這次補回。 |

刻意避開整點與 UTC 00:00（同架構的美國總經手冊實測穩定遲到 10 小時以上）。

## 已知限制

- **看不到價格位置。** COT 講的是「誰持有多少」，不是「押在哪個殖利率」。
  要做履約價層級的分析，需要 CME 的正式授權（DataMine 或已取得轉授權的資料商）。
- **週頻且延遲三天。** 報的是週二收盤部位，週五才公布。市場劇烈波動時，
  看到的是三天前的樣子。頁面最上方固定標示部位日期。
- **M4 是已實現波動，不是隱含波動。** 它講市場已經走過什麼，不是市場預期什麼。
